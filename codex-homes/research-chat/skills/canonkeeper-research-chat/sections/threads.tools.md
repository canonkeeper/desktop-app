
- `threads` — открытые нити саги (тайны, обещания, долги, конфликты, планы, подвешенные
  детали), важные первыми; `who` — нити героя под всеми именами, `query`, `kind` сужают,
  `level=all` добавляет нити отдельных книг, которые могли закрыться, `part=arcs` — арки
  по книгам. Бери для обзора, идей и письма, для вопроса «что осталось открытым». Нить —
  навигация, а не факт: важное проверяй в тексте через `read`. Ответ называет, по какую
  главу собран слой и сколько глав новее: новые главы смотри сам.
